# 字幕刷新优化 · 0.9.2+33

播放进度通知原来会重建整个右侧字幕列表；每次换句（包括进入句间空白）也会重建播放器页面，并执行字幕列表滚动。含大量 ruby 注音时，这些更新会重复解析文本、排版并更新视频控件参数。

本版将当前字幕作为独立通知源，只在当前句变化时更新画面字幕与列表高亮。视频与字幕绘制分离，单纯换句不会重建视频区域。同一句内的进度通知只更新播放控制，不更新字幕列表。字幕跟随仅在当前行离开可视区域后滚动；播放列表模式和全屏下不执行隐藏列表的跟随滚动。

假名组件只在文本变化时解析，正文与无障碍文本复用同一解析结果；可见字幕行缓存当前纯文本，隐藏时不解析。字号、语言、假名开关和辅助朗读仍会正确响应。

验证：29 项播放器页面测试和 56 项字幕组件、语言、快捷键及手机共享组件测试通过；其中新增回归直接检查同一句进度更新时视频区域与字幕行的 widget 保持不变、跨句字幕与高亮更新、字幕间隙、可见行不滚动及暂停时替换字幕。静态分析无问题。Mac 发布构建与签名校验通过。

本次只减少字幕相关刷新和布局工作，未修改解码、缓冲或文件读取参数。这些回归确认了刷新行为，尚不能据此保证所有媒体文件的音视频卡顿均已消失。
