# 测试暂停计时修复 · 0.9.1+32

测试途中保存离开、切换模块、应用进入后台或正常退出时，保存已选答案、题号及暂停时刻。再次继续测试后恢复计时，暂停期间不会触发超时交卷，成绩用时也不计入暂停期间。仍在作答时用完剩余时间则照常自动交卷。

未完成测试和成绩快照新增第 2 版计时字段，保留最初开始时间，累计暂停时长，并在继续时调整截止时间。第 1 版记录仍可读取，已保存的历史成绩不重新计算。旧版记录没有退出时刻，无法追溯扣除升级前离开的时间。

退出确认及剩余时间展示同步更新中文、日文和英文文案。页面退出和生命周期保存采用同一个存储队列，避免作答保存与暂停写入互相覆盖；正常应用退出请求会等待保存完成。强制结束进程仍无法保证收到生命周期通知。

验证覆盖：保存离开后隔天继续、后台恢复、页面卸载后重开、切换模块、取消离开、重复暂停与恢复、实际作答时间到期、已选答案与题号保留、不限时用时统计及旧版记录兼容。测试使用合成题目和临时目录，不改动个人题库或成绩。
