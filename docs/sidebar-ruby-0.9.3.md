# 侧栏假名与全屏字幕栏 · 0.9.3+34

侧边字幕列表现在与画面字幕一样，显示字幕文件已提供的汉字上方假名，并共用“显示已标注的假名”开关。复用已有的按文本缓存解析结果，仍然只在换句时刷新字幕；隐藏列表文本时不构建 ruby 内容。字幕行增加高度，为三行带注音的正文留出空间，跟随滚动按相同的行高计算。

从窗口模式进入全屏时，默认展开右侧字幕栏，不受窗口内播放列表页签选择影响。全屏字幕栏内可收起，视频上方的工具栏也提供展开／隐藏按钮。自动隐藏的播放控制只覆盖视频区域，保持字幕栏可操作。一次全屏期间手动隐藏后不会因重复的原生窗口回调而重新展开；退出全屏后再次进入则默认展开。

保留原有的播放位置、单击播放／暂停、双击全屏、快捷键和字幕跟随行为。测试覆盖普通与紧凑窗口、双击及原生全屏回调、展开／隐藏／重新进入、画面与侧栏开关同步及上方假名布局。
